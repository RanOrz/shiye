# Local Web Clipper 设计说明

## 目标

制作一个 Manifest V3 Chrome 扩展，将网页剪藏和音视频转写统一到一个入口，并把带 YAML metadata 的 Markdown 保存到用户选择的本地文件夹。

## 产品结构

扩展弹窗包含“剪藏网页”和“音视频转写”两个标签。网页剪藏读取当前标签页，提取标题、作者、发布日期、原始网址、描述和正文；音视频转写接收公开的 HTTP/HTTPS 链接，优先使用平台现成字幕，没有字幕时下载临时音频并用本地 Whisper 转写。两条流程都可以选择“AI 整理”，额外生成摘要、核心要点和标签。

本地 Flask 服务只监听 `127.0.0.1:43127`。它负责保存目录配置、Markdown 渲染、安全写文件、AI 请求和音视频后台任务。扩展首次连接时从本地服务获取配对令牌，之后所有写操作都必须携带令牌。API 只接受扩展来源、JSON 请求和 HTTP(S) 媒体链接。

## 数据流

```text
Chrome 扩展
├── 当前页面 -> DOM 清理 -> HTML 转 Markdown ─┐
└── 音视频 URL -> localhost 后台任务          ├── 可选 AI 整理
                   ├── 字幕优先               │
                   └── yt-dlp + Whisper       │
                                                └── YAML + Markdown -> 指定目录
```

## Markdown 约定

默认 frontmatter 字段为 `title`、`source`、`author`、`published`、`created`、`type`、`tags`。AI 整理启用时，正文增加“内容摘要”和“核心要点”，同时保留完整网页正文或完整转写，避免摘要替代原始内容。文件名经过跨平台字符清理；同名文件默认自动添加序号，不覆盖已有内容。

## 设置与隐私

设置页支持选择或手动填写保存根目录，分别配置 `网页剪藏` 与 `视频转写` 子目录，选择 Whisper 模型，以及配置 OpenAI-compatible 或 Ollama。API Key 仅写入本机配置文件，文件权限设为仅当前用户可读写，不进入扩展包、日志或 Git。

原始网页内容默认不离开电脑。未开启 AI 整理时，视频字幕和转写也完全留在本地；启用第三方 AI 时，只发送整理所需文本。下载的临时音频无论成功或失败都会清理。

## 错误处理

- 本地服务未运行：扩展显示启动命令，不丢失已提取的页面内容。
- 保存目录未设置或无权限：引导打开设置并重新选择。
- 链接不受支持：保留明确错误，不生成空文件。
- 字幕不可用：自动切换到音频下载和 Whisper。
- AI 未配置或调用失败：回退到未整理的完整内容，仍允许保存。
- 网页请求超过 8MB：拒绝写入并提示缩短正文，避免异常页面耗尽本地服务内存。
- 弹窗关闭：媒体任务继续运行，任务 ID 保存在扩展本地存储，重新打开后恢复进度。

## 验证范围

后端使用 `unittest` 覆盖配置权限、文件名、YAML、重复文件、鉴权、网页保存和任务状态；前端使用 Node 语法检查和浏览器手工流程检查。联调至少验证服务健康检查、首次配对、指定目录写入、网页剪藏预览、媒体错误状态和成功保存状态。
