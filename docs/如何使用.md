# 拾页：如何使用

这是一份给第一次使用者的快速指南。完整的成本、隐私和技术说明请看：[使用说明与成本评估](./使用说明与成本评估.md)。

## 一、准备环境

仅支持 macOS + Google Chrome。

请先安装：

- Python 3.11 或更新版本
- Homebrew
- FFmpeg

如果没有 FFmpeg，在终端运行：

```bash
brew install ffmpeg
```

## 二、下载项目

在终端运行：

```bash
git clone https://github.com/RanOrz/shiye.git
cd shiye
```

也可以在 GitHub 页面点击 **Code → Download ZIP**，解压后进入项目文件夹。

## 三、第一次安装

双击项目里的：

```text
setup.command
```

它会创建项目自己的 Python 环境并安装依赖。第一次安装可能需要几分钟，并会下载 Whisper 依赖。

## 四、启动本地服务

每次使用前双击：

```text
start.command
```

看到下面的内容，说明服务已经启动：

```text
[拾页] 地址：http://127.0.0.1:43127
```

这个终端窗口必须保持打开。停止服务时，在终端按 `Control + C`。

## 五、安装 Chrome 扩展

1. 打开 Chrome。
2. 地址栏输入 `chrome://extensions`。
3. 打开右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择项目里的 `extension` 文件夹。
6. 将“拾页”固定到浏览器工具栏。

代码更新后，回到 `chrome://extensions`，点击“拾页”卡片上的 `↻` 重新加载。

## 六、第一次设置保存位置

1. 点击工具栏里的拾页图标。
2. 点击左上角的文件夹按钮。
3. 选择一个本地文件夹。
4. 网页剪藏和视频转写会分别保存到该文件夹下的“网页剪藏”和“视频转写”目录。

## 七、剪藏网页

1. 打开普通网页。
2. 点击拾页图标。
3. 顶部选择“网页正文”。
4. 点击【本页】。
5. 检查正文，必要时修改。
6. 点击底部“保存正文”。

插件会自动过滤导航、广告、推荐、评论、分享和侧栏等常见噪音。

## 八、转写 YouTube / Bilibili

1. 打开拾页图标。
2. 顶部选择“音视频转写”。
3. 粘贴公开视频网址。
4. 也可以粘贴“视频标题 + 视频网址”的整段分享文本。
5. 点击“开始转写”。

处理顺序是：

```text
读取标题和时长
→ 查找平台字幕
→ 没有字幕时提取音频
→ 本地 Whisper 转写
→ 保存带时间戳的 Markdown
```

示例输出：

```markdown
[00:00:03] 大家好，今天我们来聊模型选型。
[00:00:18] 第一个重点是数据和评测体系。
```

## 九、常见问题

### “本地服务未运行”

重新双击 `start.command`，并保持终端窗口开启。

### 代码更新后界面没变化

打开 `chrome://extensions`，点击拾页卡片右下角的 `↻`。

### 视频转写失败

记录错误代码和失败阶段。常见情况包括：

- `MEDIA_METADATA`：平台元数据访问失败
- `MEDIA_DOWNLOAD_403`：平台拒绝下载媒体
- `MEDIA_URL_PRIVATE`：VPN/DNS 把网址解析成了内网地址
- `MEDIA_TRANSCRIBE_EMPTY`：Whisper 没有识别出文字

YouTube 和 Bilibili 可能因为登录状态、地区、VPN、IP 或平台接口变化而暂时不可用。

### AI 整理是否必须？

不是。不开启 AI 时，网页正文和音视频转写都可以正常保存。AI 只负责额外生成摘要、要点和标签。

## 十、数据在哪里

- 配置：`~/.local-web-clipper/config.json`
- 网页 Markdown：你选择的根目录 / `网页剪藏`
- 视频 Markdown：你选择的根目录 / `视频转写`

默认情况下，正文和本地 Whisper 转写不会上传到第三方服务。
