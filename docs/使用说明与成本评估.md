# 拾页 · 使用说明与成本评估

> 更新时间：2026-08-30

## 一句话介绍

拾页是一个本地优先的 Chrome 扩展：把当前网页或公开的 YouTube、Bilibili 等音视频链接整理成 Markdown，并保存到用户指定的本地文件夹。

## 当前能力

- 网页剪藏：点击“本页”后提取正文，过滤导航、广告、评论、推荐、分享和侧栏等噪音。
- 音视频转写：支持 YouTube、Bilibili 等 yt-dlp 可识别的公开链接。
- 转写策略：平台字幕优先；没有字幕时下载音频并使用本地 Whisper。
- 时间信息：字幕或 Whisper 分段会以 `[00:01:23] 文本` 的形式写入 Markdown。
- Markdown：包含 YAML 元数据、原始链接、完整正文/转写，文件名重复时自动编号，不覆盖旧文件。
- 后台任务：关闭扩展弹窗后，视频任务仍在本地继续运行。
- 可选 AI 整理：支持 OpenAI-compatible 接口和本地 Ollama；不开启时正文不离开电脑。

## 前置条件

### 必需

1. macOS。
2. Google Chrome。
3. Python 3.11 或更新版本；项目当前使用 Python Flask 本地服务。
4. FFmpeg：用于音频提取和媒体格式处理。
5. 可以访问目标网站的网络环境。VPN、代理或 DNS 分流可能影响 YouTube/Bilibili 下载。
6. 至少有一个本地 Markdown 保存文件夹。

### 可选

- 本地 Whisper 模型：首次使用对应模型时会下载模型文件并占用磁盘。
- Ollama：如果希望 AI 整理完全在本机运行。
- OpenAI-compatible API：如果希望使用云端模型生成摘要、要点和标签。

## 安装与启动

### 第一次安装

在 Finder 中打开项目目录：

```text
/Users/ran/local-web-clipper
```

双击 `setup.command`。它会创建项目自己的 Python 环境并安装依赖。

如果没有 FFmpeg，先执行：

```bash
brew install ffmpeg
```

### 每次使用

双击 `start.command`，看到下面的地址后保持终端窗口开启：

```text
[拾页] 地址：http://127.0.0.1:43127
```

### 加载扩展

1. Chrome 打开 `chrome://extensions`。
2. 打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择：

```text
/Users/ran/local-web-clipper/extension
```

代码更新后，在同一页面点击拾页卡片上的 `↻` 重新加载。

## 网页剪藏

1. 打开需要保存的普通网页。
2. 点击 Chrome 工具栏中的拾页图标。
3. 顶部选择“网页正文”。
4. 点击【本页】。
5. 检查正文内容，必要时手动修改。
6. 点击底部“保存正文”。
7. 保存成功后，点击提示中的文件名可以直接打开 Markdown 文件。

## 视频转文字

1. 打开拾页扩展。
2. 顶部切换到“音视频转写”。
3. 粘贴纯链接，或粘贴“标题 + 链接”的整段分享文本。
4. 点击“开始转写”。
5. 等待“读取媒体信息 → 查找字幕 → 提取音频 → 本地转写”。
6. 任务完成后，点击文件名打开 Markdown。

支持两类常见 Bilibili 输入：

```text
https://www.bilibili.com/video/BV...
https://www.bilibili.com/video/BV...?share_source=copy_web
```

YouTube 的 Shorts、watch、youtu.be 短链接也会统一识别。平台限制、登录限制、地区限制或 403/412 仍可能导致下载失败；失败时请记录错误代码和阶段。

## 输出文件结构

默认情况下：

```text
选择的根目录/
├── 网页剪藏/
│   └── 页面标题.md
└── 视频转写/
    └── 视频标题.md
```

视频正文示例：

```markdown
## 完整转写

[00:00:03] 大家好，今天我们来聊模型选型。
[00:00:18] 第一个重点是数据和评测体系。
```

## 隐私与安全

- 本地服务只监听 `127.0.0.1:43127`。
- 未启用 AI 整理时，网页正文、字幕和 Whisper 转写都留在本机。
- AI 整理开启后，只有待整理文本会发送到配置的模型服务。
- API Key 保存在本机配置文件中，不写入扩展代码。
- 下载的临时音频处理结束后会清理。
- 只处理自己有权访问、下载和转写的内容。

## 成本评估

### 当前默认方案：本地 Whisper

当前项目默认使用本地 Whisper 转写，因此没有按分钟支付的转写 API 费用：

| 成本项 | 是否产生费用 | 说明 |
|---|---:|---|
| 软件依赖 | 通常为 0 | Python、yt-dlp、Whisper、FFmpeg 均可免费使用；需遵守各自许可证 |
| 视频/音频下载 | 通常为 0 | 由本机网络和目标平台提供；不包含付费会员或代理费用 |
| Whisper 转写 | 0 美元 API 费用 | 使用本机 CPU/GPU 计算，会消耗时间、电量和磁盘 |
| 磁盘 | 取决于模型 | 模型越大，占用空间和内存越多 |
| VPN/代理 | 取决于服务商 | YouTube/Bilibili 是否可访问由你的网络环境决定 |

本地方案的实际成本主要是电脑运行时间。粗略估算公式：

```text
电费 ≈ 转写时长 × 实际处理倍速对应的小时数 × 电脑功耗（kW）× 当地电价
```

例如电脑平均 50W、处理 1 小时音频耗时 30 分钟、电价按 1 元/度估算，电费约为 0.025 元；实际速度会因 Whisper 模型、CPU/GPU 和音频编码差异很大。

### 云端转写的参考成本

项目目前没有把云端语音转写作为默认路径；如果以后接入 OpenAI 的 GPT Transcribe，官方当前标价为 `$0.0045/分钟`。[官方模型价格](https://developers.openai.com/api/docs/models/gpt-transcribe)

按此价格估算：

| 音频时长 | 参考费用 |
|---:|---:|
| 10 分钟 | $0.045 |
| 60 分钟 | $0.27 |
| 100 小时 | $27 |

实际账单还可能受到模型、批处理、汇率和服务政策变化影响。

### AI 摘要/要点的成本

AI 整理是单独的一步，不负责基础转写。当前可配置 OpenAI-compatible 接口或 Ollama：

- Ollama：本地运行，通常没有 API 费用，但需要额外下载模型和消耗本机资源。
- 云端模型：按输入和输出 token 计费。例如官方当前列出的 GPT-4o mini 文本价格是每 100 万输入 token `$0.15`、每 100 万输出 token `$0.60`。[官方模型价格](https://developers.openai.com/api/docs/models/gpt-4o-mini)

对个人使用来说，摘要成本通常远低于视频下载和本地计算成本；但长视频完整转写后再发送给云端整理，费用和隐私暴露都会增加。

## 技术选型说明

| 组件 | 选择 | 原因 |
|---|---|---|
| Chrome 扩展 | Manifest V3 + 原生 HTML/CSS/JS | 安装简单，能读取当前页面并保持轻量 |
| 本地服务 | Flask | 负责文件写入、配置和后台任务，避免扩展直接操作本地文件 |
| 媒体解析 | yt-dlp | 同时覆盖 YouTube、Bilibili 和大量其他平台 |
| 字幕 | 平台字幕优先 | 成本低、速度快、通常比语音识别更贴近原文 |
| 语音识别 | 本地 Whisper | 不上传音频，长期使用没有按分钟费用 |
| 存储 | Markdown + YAML frontmatter | 可迁移、可被 Obsidian、VS Code 等工具直接使用 |
| AI 整理 | OpenAI-compatible / Ollama | 兼容云端和本地两种隐私与成本策略 |

### 平台限制说明

yt-dlp 的平台适配会随网站变化。YouTube 当前可能要求 PO Token，缺失时格式请求会返回 403；Bilibili 也可能因接口、地区、账号或 IP 返回 412。遇到此类错误时，优先更新 yt-dlp、检查 VPN/代理和登录状态，不要把失败简单归因于 Markdown 或 Whisper。

## 常见问题排查

### 显示“本地服务未运行”

重新双击 `start.command`，并保持终端窗口开启。

### 显示 `MEDIA_METADATA`

平台元数据请求失败。先检查网址是否完整、VPN 是否可访问目标网站，并确认 yt-dlp 是最新版。

### 显示 `MEDIA_DOWNLOAD_403`

平台拒绝媒体流下载，常见于 YouTube 的登录、IP、PO Token 或地区限制。

### 显示 `MEDIA_URL_PRIVATE`

安全校验认为 DNS 将网址解析到了本机/局域网地址。检查 VPN 的 DNS 分流，不建议直接关闭安全校验。

### 转写完成但没有时间戳

确认本地服务和扩展都已重启/重新加载；新版会把字幕或 Whisper 分段写为 `[HH:MM:SS]` 格式。
